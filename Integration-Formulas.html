Formula (i)Some standard integrals
∫xn dx = xn + 1n + 1 + Cn ≠ −1

Proof

  1. Differentiate the right-hand side, treating n as a constant:
    ddx (xn + 1n + 1) = 1n + 1 · (n + 1) xn = xn
  2. That is the integrand, so the right-hand side is an antiderivative.

Note The division by n + 1 is what forces n ≠ −1. The case n = −1 is a different formula altogether — entry (xiv).

Note Putting n = 0 gives the Summary's ‘particularly’ case, ∫1 dx = x + C.

Formula (ii)Some standard integrals
∫cos x dx = sin x + C

Proof

  1. ddx (sin x) = cos x, which is the integrand.

Note Every entry in this group is one line of the derivative table read from right to left. Learning the derivatives properly is learning these.

Formula (iii)Some standard integrals
∫sin x dx = −cos x + C

Proof

  1. ddx (−cos x) = −(−sin x) = sin x.

Trap The minus sign is the whole question. ddx (cos x) = −sin x, so undoing it needs a minus in front.

Formula (iv)Some standard integrals
∫sec2 x dx = tan x + C

Proof

  1. ddx (tan x) = sec2 x.

Note Valid on any interval avoiding x = (2n + 1)π2, where tan and sec are undefined.

Formula (v)Some standard integrals
∫cosec2 x dx = −cot x + C

Proof

  1. ddx (cot x) = −cosec2 x, so ddx (−cot x) = cosec2 x.

Trap Both cot and cosec carry a minus in their derivatives. Here one minus is used up cancelling the other.

Formula (vi)Some standard integrals
∫sec x tan x dx = sec x + C

Proof

  1. ddx (sec x) = sec x tan x.

Note Read as a product: the integrand is exactly the derivative of one of its own factors.

Formula (vii)Some standard integrals
∫cosec x cot x dx = −cosec x + C

Proof

  1. ddx (cosec x) = −cosec x cot x, so ddx (−cosec x) = cosec x cot x.
Formula (viii)Some standard integrals
∫1√1 − x2 dx = sin−1 x + C

Proof

  1. Let y = sin−1 x, so x = sin y with y ∈ [−π2, π2].
  2. Differentiating x = sin y: 1 = cos y dydx, so dydx = 1cos y.
  3. On that branch cos y ≥ 0, so cos y = √1 − sin2 y = √1 − x2.
  4. Hence ddx sin−1 x = 1√1 − x2, which is the integrand.

Note Read this one together with (ix): the same integrand has two standard answers.

Formula (ix)Some standard integrals
∫1√1 − x2 dx = −cos−1 x + C

Proof

  1. ddx cos−1 x = −1√1 − x2, so ddx (−cos−1 x) = 1√1 − x2.

Note Both (viii) and (ix) are correct, and they do not contradict each other. Since sin−1x + cos−1x = π2 for every x in [−1, 1], the two answers differ by the constant π2 — and an antiderivative is only ever determined up to a constant, which is what C absorbs.

Trap Do not ‘correct’ a classmate who wrote one when you wrote the other. Marks are lost only for a wrong derivative, not for a different constant.

Formula (x)Some standard integrals
∫11 + x2 dx = tan−1 x + C

Proof

  1. Let y = tan−1 x, so x = tan y with y ∈ (−π2, π2).
  2. Differentiating: 1 = sec2 y dydx.
  3. sec2 y = 1 + tan2 y = 1 + x2.
  4. So dydx = 11 + x2.

Note No square root and no restriction on x: this one holds on the whole real line, unlike (viii).

Formula (xi)Some standard integrals
∫11 + x2 dx = −cot−1 x + C

Proof

  1. ddx cot−1 x = −11 + x2, so the negative of it differentiates to the integrand.

Note The same pairing as (viii) and (ix): tan−1x + cot−1x = π2, so the two answers differ by a constant.

Formula (xii)Some standard integrals
∫ex dx = ex + C

Proof

  1. ddx ex = ex.

Note The only function that is its own derivative, and therefore its own integral — up to the constant.

Formula (xiii)Some standard integrals
∫ax dx = axlog a + Ca > 0, a ≠ 1

Proof

  1. Write ax in exponential form: ax = ex log a.
  2. Differentiating the claimed answer,
    ddx (ex log alog a) = 1log a · ex log a · log a = ex log a = ax
  3. which is the integrand.

Note a = 1 is excluded because log 1 = 0 and the formula would divide by zero — and rightly so: ∫1x dx = ∫1 dx = x + C, a different answer.

Formula (xiv)Some standard integrals
∫1x dx = log |x| + C

Proof

Note The modulus is not decoration. 1x is defined for x < 0 as well, and log x is not.

  1. For x > 0: |x| = x, and ddx log x = 1x. ✓
  2. For x < 0: |x| = −x, and by the chain rule
    ddx log(−x) = 1−x · (−1) = 1x
  3. ✓ as well. So on either side of 0, log|x| differentiates to 1x.

Trap The two branches are separate intervals, so strictly the constants may differ on each. In school work one C is written, but that is why the formula is never used across x = 0.

Formula (i)By substitution
∫tan x dx = log |sec x| + C

Proof

  1. Write tan x = sin xcos x and put t = cos x, so dt = −sin x dx.
    ∫tan x dx = ∫sin xcos x dx = −∫1t dt = −log|t| + C
  2. Restoring t: −log|cos x| + C = log|cos x|−1 + C = log|sec x| + C.

Note Both forms are standard. The Summary prints log|sec x|; −log|cos x| is the same thing and is equally acceptable.

Formula (ii)By substitution
∫cot x dx = log |sin x| + C

Proof

  1. cot x = cos xsin x, and the numerator is the derivative of the denominator.
  2. Put t = sin x, dt = cos x dx:
    ∫cot x dx = ∫1t dt = log|t| + C = log|sin x| + C

Note Compare with (i): tan needs a minus and cot does not, because ddx cos x carries a minus and ddx sin x does not.

Formula (iii)By substitution
∫sec x dx = log |sec x + tan x| + C

Proof

Note The trick is to multiply by a form of 1 chosen so that the numerator becomes the derivative of the denominator.

  1. Multiply above and below by (sec x + tan x):
    ∫sec x dx = ∫sec x (sec x + tan x)sec x + tan x dx = ∫sec2 x + sec x tan xsec x + tan x dx
  2. Now put t = sec x + tan x. Then dt = (sec x tan x + sec2 x) dx — exactly the numerator.
  3. So the integral is ∫1t dt = log|t| + C = log|sec x + tan x| + C.

Note The same multiplier explains the alternative form log|tan(π4 + x2)| + C, which some books print instead.

Formula (iv)By substitution
∫cosec x dx = log |cosec x − cot x| + C

Proof

  1. Multiply above and below by (cosec x − cot x):
    ∫cosec x dx = ∫cosec2 x − cosec x cot xcosec x − cot x dx
  2. Put t = cosec x − cot x. Then dt = (−cosec x cot x + cosec2 x) dx — again exactly the numerator.
  3. So the value is log|t| + C = log|cosec x − cot x| + C.

Trap The multiplier is (cosec x − cot x), with a minus, while for sec it was a plus. Using the wrong sign leaves an integral that does not close up.

Formula (i)Integrals of some special functions
∫1x2 − a2 dx = 12a log |x − ax + a| + C

Proof

  1. Factorise and split by partial fractions:
    1(x − a)(x + a) = 12a [1x − a − 1x + a]
  2. Check by recombining: (x + a) − (x − a)(x − a)(x + a) = 2ax2 − a2. ✓
  3. Integrating each piece gives 12a [log|x − a| − log|x + a|] + C.
  4. Combining the logarithms gives the stated form.

Note The order inside the logarithm matters: it is x − ax + a. Compare (ii), where the signs are the other way round.

Formula (ii)Integrals of some special functions
∫1a2 − x2 dx = 12a log |a + xa − x| + C

Proof

  1. Same method with the factors the other way: a2 − x2 = (a − x)(a + x).
    1(a − x)(a + x) = 12a [1a − x + 1a + x]
  2. Integrating: 12a [−log|a − x| + log|a + x|] + C — the first term picks up a minus from the chain rule.
  3. That is 12a log|a + xa − x| + C.

Note This is just (i) with a sign change, since 1a2 − x2 = −1x2 − a2. Negating (i)'s answer flips the fraction inside the log, which is exactly what is printed here.

Formula (iii)Integrals of some special functions
∫1x2 + a2 dx = 1a tan−1 xa + C

Proof

  1. Substitute x = a tanθ, so dx = a sec2θ dθ.
  2. The denominator becomes a2tan2θ + a2 = a2sec2θ.
    ∫1x2 + a2 dx = ∫a sec2θa2 sec2θ dθ = 1a∫1 dθ = θa + C
  3. And θ = tan−1 xa.

Note The 1a outside and the xa inside are both needed. Dropping either is the commonest error in this whole group.

Formula (iv)Integrals of some special functions
∫1√x2 − a2 dx = log |x + √x2 − a2| + C

Proof

  1. Substitute x = a secθ, so dx = a secθ tanθ dθ and √x2 − a2 = a tanθ.
    ∫a secθ tanθa tanθ dθ = ∫secθ dθ = log|secθ + tanθ| + C
  2. using the substitution result proved above.
  3. Restoring: secθ = xa and tanθ = √x2 − a2a, so the value is
    log|x + √x2 − a2a| + C = log|x + √x2 − a2| − log a + C
  4. and the constant −log a is absorbed into C.

Note That last absorption is why no 1a appears in the answer, unlike (iii).

Formula (v)Integrals of some special functions
∫1√a2 − x2 dx = sin−1 xa + C

Proof

  1. Substitute x = a sinθ, so dx = a cosθ dθ and √a2 − x2 = a cosθ.
    ∫a cosθa cosθ dθ = ∫1 dθ = θ + C
  2. And θ = sin−1 xa.

Note No 1a outside: the a in dx cancels the a in the root. Contrast (iii), where the square in the denominator leaves one behind.

Formula (vi)Integrals of some special functions
∫1√x2 + a2 dx = log |x + √x2 + a2| + C

Proof

  1. Substitute x = a tanθ, so dx = a sec2θ dθ and √x2 + a2 = a secθ.
    ∫a sec2θa secθ dθ = ∫secθ dθ = log|secθ + tanθ| + C
  2. Restoring secθ = √x2 + a2a and tanθ = xa gives log|x + √x2 + a2| − log a + C, and the −log a is absorbed.

Trap A plus under the root gives a logarithm; a minus gives sin−1. Deciding which by looking at the sign is the first thing to do with any such integral.

Formula (i)Integration by parts
∫f1(x) · f2(x) dx = f1(x) ∫f2(x) dx − ∫[ddx f1(x) · ∫f2(x) dx] dx

Proof

Note The rule is the product rule for derivatives, integrated.

  1. Start from the product rule for two functions u and v:
    ddx (uv) = u dvdx + v dudx
  2. Integrate both sides with respect to x:
    uv = ∫u dvdx dx + ∫v dudx dx
  3. Rearranging gives the rule in its usual form:
    ∫u dv = uv − ∫v du
  4. Writing u = f1(x) and v = ∫f2(x) dx gives exactly the Summary's statement.

Note Choosing the first function. The Summary's advice is to take as the second function the one whose integral is well known. The usual order for the first function is ILATE — Inverse trigonometric, Logarithmic, Algebraic, Trigonometric, Exponential.

Trap The formula does not finish the job: it trades one integral for another. Choosing the wrong first function trades it for a harder one.

Formula (ii)Integration by parts
∫ex [f(x) + f ′(x)] dx = ex f(x) + C

Proof

  1. Split the integral in two:
    ∫ex f(x) dx + ∫ex f ′(x) dx
  2. Take the first by parts, with f(x) as the first function and ex as the second:
    ∫ex f(x) dx = f(x) ex − ∫f ′(x) ex dx
  3. Add the second integral back: the two ∫ex f ′(x) dx terms cancel exactly.
  4. What is left is ex f(x) + C.

Note The Summary writes the answer as ∫ex f(x) dx + C, which is the same statement.

Note Recognising it is the whole skill. ∫ex(1x − 1x2) dx has f = 1x and f ′ = −1x2, so the answer is exx + C without any working at all.

Formula (i)Some special types of integrals
∫√x2 − a2 dx = x2√x2 − a2 − a22 log |x + √x2 − a2| + C

Proof

Note All three of these are integration by parts with 1 as the second function.

  1. Parts with u = √x2 − a2, dv = dx:
    ∫√x2 − a2 dx = x√x2 − a2 − ∫x2√x2 − a2 dx
  2. Write the new numerator as x2 = (x2 − a2) + a2:
    ∫x2√x2 − a2 dx = ∫√x2 − a2 dx + a2∫1√x2 − a2 dx
  3. Call the original integral I, and use the standard form proved above for the last term. The first equation becomes
    I = x√x2 − a2 − I − a2 log|x + √x2 − a2|
  4. Solving for I,
    2I = x√x2 − a2 − a2 log|x + √x2 − a2|

Note The integral reappearing on the right, and being solved for, is the point of the method. Expect it in all three of these.

Formula (ii)Some special types of integrals
∫√x2 + a2 dx = x2√x2 + a2 + a22 log |x + √x2 + a2| + C

Proof

  1. Parts with u = √x2 + a2, dv = dx:
    I = x√x2 + a2 − ∫x2√x2 + a2 dx
  2. Split x2 = (x2 + a2) − a2 this time:
    ∫x2√x2 + a2 dx = I − a2 log|x + √x2 + a2|
  3. So I = x√x2 + a2 − I + a2 log|x + √x2 + a2|, giving 2I and hence the result.

Note Compare with (i): the only difference is the sign of the a2 term, and it traces back to how x2 was split.

Formula (iii)Some special types of integrals
∫√a2 − x2 dx = x2√a2 − x2 + a22 sin−1 xa + C

Proof

  1. Parts with u = √a2 − x2, dv = dx:
    I = x√a2 − x2 + ∫x2√a2 − x2 dx
  2. (the sign changes because ddx√a2 − x2 = −x√a2 − x2.)
  3. Split x2 = −(a2 − x2) + a2:
    ∫x2√a2 − x2 dx = −I + a2 sin−1xa
  4. So I = x√a2 − x2 − I + a2 sin−1xa, and 2I gives the result.

Trap This is the one whose second term is an inverse sine, not a logarithm — because the standard form underneath it is (v) of the previous group, not (iv) or (vi).
