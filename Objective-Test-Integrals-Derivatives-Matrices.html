1Integrals[1]
Evaluate ∫log xx dx.

Substitution

Note The integrand is f ′(x) f(x) with f = log x, so it integrates as f22.

  1. Put t = log x, so dt = dxx.
  2. The integral becomes ∫t dt = t22 + C.
  3. Restore t: (log x)22 + C.

Trap log|log x| is the answer to ∫1x log x dx — a different integrand.

Answer (log x)22 + C

2Integrals[1]
Evaluate ∫ex(1x − 1x2) dx.

The e x[f + f ′] identity

Note Recognise the shape ∫ex[f(x) + f ′(x)] dx = ex f(x) + C. Nothing has to be integrated by parts once you see it.

  1. Take f(x) = 1x. Then f ′(x) = −1x2.
  2. The bracket is exactly f + f ′, so the value is ex f(x) = exx + C.

Trap The minus sign belongs to f ′, not to the answer.

Answer exx + C

3Integrals[1]
Evaluate ∫1x2 + 4x + 8 dx.

Completing the square

  1. x2 + 4x + 8 = (x + 2)2 + 22.
  2. Use ∫1t2 + a2 dx = 1a tan−1ta + C with t = x + 2, a = 2.
  3. Value: 12 tan−1x + 22 + C.

Trap The 1a outside and the a underneath are the same a = 2. Writing 4 in either place is the usual slip.

Answer 12 tan−1x + 22 + C

4Integrals[1]
Evaluate ∫x(x + 1)(x + 2) dx.

Partial fractions

  1. x(x + 1)(x + 2) = Ax + 1 + Bx + 2.
  2. Cover-up at x = −1: A = −11 = −1. At x = −2: B = −2−1 = 2.
  3. So the integral is −log|x + 1| + 2 log|x + 2| + C.

Note Check the signs by adding the fractions back, or by comparing the coefficient of x: −1 + 2 = 1. ✓

Answer −log|x + 1| + 2 log|x + 2| + C

5Integrals[1]
Evaluate ∫sin3 x dx.

Odd power of sine

  1. Split off one sine: sin3 x = (1 − cos2 x) sin x.
  2. Put t = cos x, dt = −sin x dx.
  3. The integral becomes −∫(1 − t2) dt = −t + t33 + C.
  4. Restore: −cos x + cos3 x3 + C.

Note For an odd power of sine or cosine, peel one factor off and substitute the other function. Only even powers need the double-angle identities.

Answer −cos x + cos3 x3 + C

6Integrals[1]
Evaluate ∫1sin2 x cos2 x dx.

Writing 1 as sin² + cos²

  1. Replace the 1 on top by sin2 x + cos2 x.
  2. The integrand splits into 1cos2 x + 1sin2 x = sec2 x + cosec2 x.
  3. Integrating: tan x − cot x + C.

Note Every term of the answer must differentiate back. d(−cot x)/dx = +cosec2 x, which is why the sign is a minus.

Answer tan x − cot x + C

7Integrals[1]
Evaluate ∫π20sin xsin x + cos x dx.

The a − x reflection property

Note Never try to integrate this directly. It is the standard ∫a0f(x) dx = ∫a0f(a − x) dx question.

  1. Call the value I. Replacing x by π2 − x swaps sine and cosine, so I = ∫π20cos xcos x + sin x dx.
  2. Add the two forms: 2I = ∫π201 dx = π2.
  3. Hence I = π4.

Note The same trick gives π4 for the cosine version, and the two must add to π2.

Answer π4

8Integrals[1]
Evaluate ∫20|x − 1| dx.

Splitting a modulus at its zero

  1. |x − 1| changes definition at x = 1, which lies inside [0, 2], so the integral must be split there.
  2. On [0, 1], |x − 1| = 1 − x; on [1, 2] it is x − 1.
  3. ∫10(1 − x) dx + ∫21(x − 1) dx = 12 + 12 = 1.

Trap Integrating x − 1 straight through from 0 to 2 gives 0 — the two halves cancel. A modulus can never integrate to less than the area it encloses.

Answer 1

9Integrals[1]
Evaluate ∫x2 ex dx.

Integration by parts, twice

  1. Parts with u = x2: ∫x2 ex dx = x2ex − 2∫x ex dx.
  2. Parts again: ∫x ex dx = ex(x − 1) + C.
  3. So the value is x2ex − 2ex(x − 1) = ex(x2 − 2x + 2) + C.

Note The signs alternate: +x2, −2x, +2. Differentiate the answer back if you are unsure — the cross terms must cancel.

Answer ex(x2 − 2x + 2) + C

10Integrals[1]
Evaluate ∫√x2 + 4 dx.

Standard form √(x² + a²)

  1. ∫√x2 + a2 dx = x2√x2 + a2 + a22 log|x + √x2 + a2| + C.
  2. Here a2 = 4, so a22 = 2.

Trap The coefficient of the log is a22 = 2, not a2 = 4. And a positive sign under the root means a logarithm, never a sin−1.

Answer x2√x2 + 4 + 2 log|x + √x2 + 4| + C

11Integrals[1]
Evaluate ∫1√9 − 4x2 dx.

Taking the coefficient of x² outside

  1. 9 − 4x2 = 4(94 − x2), so √9 − 4x2 = 2√94 − x2.
  2. The integral is 12∫1√(32)2 − x2 dx = 12 sin−1x32 + C.
  3. And x32 = 2x3.

Note Two things scale: the 12 that comes out of the root, and the argument, which becomes 2x3.

Answer 12 sin−12x3 + C

12Integrals[1]
Evaluate ∫311x(x + 1) dx.

Partial fractions, then limits

  1. 1x(x + 1) = 1x − 1x + 1.
  2. Antiderivative: log|x| − log|x + 1| = log xx + 1.
  3. At 3: log 34. At 1: log 12.
  4. Difference: log 34 − log 12 = log (34 × 2) = log 32.

Trap Subtracting the logs the wrong way round gives log 23, which is negative — impossible here, since the integrand is positive on [1, 3].

Answer log 32

13Integrals[1]
Evaluate ∫tan−1 x dx.

Parts with the second function 1

  1. Write the integrand as tan−1 x · 1 and take u = tan−1 x, dv = dx.
  2. = x tan−1 x − ∫x1 + x2 dx.
  3. That last integral is 12 log(1 + x2) by the substitution t = 1 + x2.
  4. Value: x tan−1 x − 12 log(1 + x2) + C.

Note The same device — a hidden second function 1 — does ∫log x dx and ∫sin−1 x dx.

Answer x tan−1 x − 12 log(1 + x2) + C

14Integrals[1]
Evaluate ∫π0x sin x1 + cos2 x dx.

The x f(sin x) property

Note For ∫π0x f(sin x) dx the x can always be replaced by π2, because ∫π0x f(sin x) dx = π2∫π0f(sin x) dx.

  1. Apply the property: I = π2∫π0sin x1 + cos2 x dx.
  2. Put t = cos x, dt = −sin x dx; the limits 0 and π become 1 and −1.
  3. I = π2∫1−111 + t2 dt = π2 [tan−1 t] from −1 to 1 = π2 · π2.
  4. Hence I = π24.

Trap Forgetting that cos x is even in the substituted integral — the limits run from 1 down to −1 and the minus sign turns them back round.

Answer π24

15Applications of Derivatives[1]
The radius of a circle is increasing at 3 cm/s. How fast is its area increasing when the radius is 10 cm?

Related rates: chain rule in t

  1. A = πr2, so dAdt = 2πr drdt.
  2. Put r = 10 and drdt = 3: dAdt = 2π(10)(3) = 60π cm2/s.

Note The rate asked for is always the one on the left; everything else is data. Differentiate the formula with respect to t, never with respect to r.

Answer 60π cm2/s

16Applications of Derivatives[1]
The volume of a cube is increasing at 9 cm3/s. How fast is its surface area increasing when the edge is 10 cm?

Two related rates linked by dx/dt

  1. V = x3 gives dVdt = 3x2 dxdt.
  2. At x = 10: 9 = 300 dxdt, so dxdt = 0·03 cm/s.
  3. S = 6x2 gives dSdt = 12x dxdt = 12(10)(0·03) = 3·6 cm2/s.

Note The edge rate dxdt is the bridge. Find it first; never try to relate S to V directly under time.

Answer 3·6 cm2/s

17Applications of Derivatives[1]
The function f(x) = 2x3 − 3x2 − 36x + 7 is strictly increasing on:

Sign of the first derivative

  1. f ′(x) = 6x2 − 6x − 36 = 6(x − 3)(x + 2).
  2. The roots −2 and 3 cut the line into three parts.
  3. A product of two factors is positive outside the roots, so f ′ > 0 on (−∞, −2) and on (3, ∞).

Trap The roots of f ′ are −2 and 3, not −3 and 2. Factorise 6(x2 − x − 6) carefully: the middle coefficient is −1.

Answer (−∞, −2) ∪ (3, ∞)

18Applications of Derivatives[1]
The function f(x) = x + 1x is strictly decreasing on:

A derivative with a break in the domain

  1. f ′(x) = 1 − 1x2 = x2 − 1x2.
  2. The denominator is positive wherever it is defined, so the sign is that of x2 − 1.
  3. x2 − 1 < 0 for −1 < x < 1.

Trap x = 0 is not in the domain, so the answer is two intervals, not one. Writing (−1, 1) claims f is defined and decreasing across a vertical asymptote.

Answer (−1, 0) ∪ (0, 1)

19Applications of Derivatives[1]
The equation of the tangent to the circle x2 + y2 = 25 at the point (3, 4) is:

Implicit differentiation, then point-slope

  1. Differentiate x2 + y2 = 25 implicitly: 2x + 2y dydx = 0, so dydx = −xy.
  2. At (3, 4) the slope is −34.
  3. y − 4 = −34(x − 3) ⇒ 3x + 4y = 25.

Note For a circle centred at the origin the tangent at (x1, y1) is always xx1 + yy1 = r2 — a one-line check on the answer.

Answer 3x + 4y = 25

20Applications of Derivatives[1]
At which point on the curve y = x2 − 2x + 3 is the tangent parallel to the line y = 2x − 1?

Matching the slope

  1. Parallel lines have equal slopes, and the given line has slope 2.
  2. dydx = 2x − 2. Set 2x − 2 = 2 ⇒ x = 2.
  3. The point must lie on the curve: y = 4 − 4 + 3 = 3, giving (2, 3).

Trap Having found x, put it back into the curve. (2, 4) is what comes out of y = x2 alone, with the −2x + 3 dropped.

Answer (2, 3)

21Applications of Derivatives[1]
The equation of the normal to the parabola y2 = 4x at the point (1, 2) is:

Normal slope is the negative reciprocal

  1. Differentiate y2 = 4x: 2y dydx = 4, so dydx = 2y.
  2. At (1, 2) the tangent slope is 1, so the normal slope is −1.
  3. y − 2 = −1(x − 1) ⇒ x + y = 3.

Trap The normal slope is −1/m, not −m. Here they happen to look alike; in general they do not.

Answer x + y = 3

22Applications of Derivatives[1]
The maximum value of sin x + cos x is:

Amplitude of a sin + b cos

  1. f ′(x) = cos x − sin x = 0 gives tan x = 1, i.e. x = π4.
  2. f(π4) = 1√2 + 1√2 = √2.
  3. f ″(x) = −sin x − cos x is negative there, so it is a maximum.

Note In general a sin x + b cos x oscillates between ±√a² + b². With a = b = 1 that is √2, so no calculus is really needed.

Answer √2

23Applications of Derivatives[1]
The absolute maximum value of f(x) = x3 − 3x on [0, 2] is:

Closed interval: test the ends as well

  1. f ′(x) = 3x2 − 3 = 0 gives x = ±1; only x = 1 lies in [0, 2].
  2. Compare f at the critical point and at both endpoints: f(0) = 0, f(1) = −2, f(2) = 8 − 6 = 2.
  3. The largest of these is 2, at x = 2.

Trap On a closed interval the absolute maximum can sit at an endpoint, where f ′ need not be zero. Testing only the stationary points misses it.

Answer 2

24Applications of Derivatives[1]
For f(x) = x3, the point x = 0 is:

When the second derivative test fails

  1. f ′(x) = 3x2, which is 0 at x = 0, so it is a stationary point.
  2. f ″(x) = 6x is also 0 there, so the second derivative test gives no verdict.
  3. Fall back on the sign of f ′: 3x2 > 0 on both sides, so f increases through 0 without turning.

Note A stationary point is not automatically a turning point. x = 0 here is a point of inflection with a horizontal tangent.

Answer neither a local maximum nor a local minimum

25Applications of Derivatives[1]
The largest rectangle that can be inscribed in a circle of radius a has area:

Maximise the square of the area

  1. Let the sides be x and y. The diagonal is the diameter, so x2 + y2 = 4a2 and A = x√4a² − x².
  2. Maximise A2 = x2(4a2 − x2) instead — the same x maximises both.
  3. d(A2)dx = 8a2x − 4x3 = 0 gives x2 = 2a2, so x = y = a√2.
  4. The rectangle is a square and A = 2a2.

Note Maximising A2 rather than A avoids the square root entirely; it is legitimate because A > 0 and squaring is increasing on positives.

Answer 2a2

26Applications of Derivatives[1]
Two positive numbers have sum 16 and the sum of their cubes is least. The numbers are:

One variable, then the second derivative

  1. Let the numbers be x and 16 − x, and S = x3 + (16 − x)3.
  2. dSdx = 3x2 − 3(16 − x)2 = 0 ⇒ x2 = (16 − x)2 ⇒ x = 8.
  3. d2Sdx2 = 6x + 6(16 − x) = 96 > 0, so it is a minimum.

Note x2 = (16 − x)2 also allows x = −(16 − x), which has no solution here. Always check both roots of a squared equation.

Answer 8 and 8

27Applications of Derivatives[1]
The function f(x) = x2e−x is strictly increasing on:

Product rule, then the sign of the polynomial factor

  1. f ′(x) = 2x e−x − x2 e−x = x e−x(2 − x).
  2. e−x > 0 always, so the sign is that of x(2 − x).
  3. x(2 − x) > 0 exactly between the roots, i.e. on (0, 2).

Trap x(2 − x) has a negative leading coefficient, so it is positive between the roots, not outside them — the reverse of the usual case.

Answer (0, 2)

28Matrices and Determinants[1]
If A is a square matrix of order 3 and |A| = 4, then |2A| is:

|kA| = kⁿ|A|

  1. Multiplying a matrix by k multiplies every one of its n rows by k, and a determinant is linear in each row separately.
  2. So |kA| = kn|A| for an n × n matrix.
  3. Here n = 3 and k = 2: |2A| = 23 × 4 = 32.

Trap 2 × 4 = 8 treats the determinant as if it scaled once. The exponent is the order, not the number of rows you happen to look at.

Answer 32

29Matrices and Determinants[1]
If A is a square matrix of order 3 with |A| = 5, then |adj A| is:

|adj A| = |A|ⁿ⁻¹

  1. A (adj A) = |A| In. Take determinants of both sides.
  2. |A| · |adj A| = | |A| In | = |A|n.
  3. Divide by |A|: |adj A| = |A|n − 1 = 52 = 25.

Note For a 3 × 3 the index is 2, so the answer is a square — not |A| itself, and not |A|3.

Answer 25

31Matrices and Determinants[1]
If A is a skew-symmetric matrix of order 3, then |A| is:

Odd order forces the determinant to vanish

  1. Skew-symmetric means A′ = −A.
  2. Taking determinants: |A| = |A′| = |−A| = (−1)3|A| = −|A|.
  3. So 2|A| = 0, giving |A| = 0.

Note The argument needs the order to be odd. A 2 × 2 skew-symmetric matrix has determinant a2 ≥ 0, which is usually not zero.

Answer 0

32Matrices and Determinants[1]
The values of x for which x218x = 0 are:

  1. x218x = x · x − 2 · 18 = x2 − 36.
  2. x2 − 36 = 0 ⇒ x2 = 36 ⇒ x = ±6.

33Matrices and Determinants[1]
The value of 1ab + c1bc + a1ca + b is:

Creating a repeated column

  1. Apply C2 → C2 + C3. Every entry of the new second column becomes a + b + c.
  2. Take the common factor (a + b + c) out of that column, leaving a column of 1s.
  3. The first column is also a column of 1s, so two columns are identical and the determinant is 0.

Note Any determinant with two equal rows or two equal columns is 0. Spotting the combination that produces one is faster than expanding.

Answer 0

34Matrices and Determinants[1]
For two square matrices A and B of the same order, (A + B)2 = A2 + 2AB + B2 holds:

Matrix multiplication does not commute

  1. (A + B)2 = (A + B)(A + B) = A2 + AB + BA + B2.
  2. That equals A2 + 2AB + B2 exactly when AB + BA = 2AB, i.e. when BA = AB.
  3. So the identity is a statement about commuting, nothing else.

Note A concrete counter-example settles it: with A = 1101 and B = 1011, AB ≠ BA and the identity fails.

Answer if and only if AB = BA

35Matrices and Determinants[1]
For A = 1−2320−1145, the cofactor A23 is:

Minor, then the chessboard sign

  1. Delete row 2 and column 3, leaving the minor M23 = 1−214 = 4 + 2 = 6.
  2. The cofactor carries the sign (−1)i + j = (−1)2 + 3 = −1.
  3. A23 = −1 × 6 = −6.

Trap The minor and the cofactor differ only by that sign, and it is negative whenever i + j is odd. Quoting the minor is the commonest slip.

39Matrices and Determinants[1]

40Matrices and Determinants[1]
The system x + 2y = 3, 2x + 4y = 8 has:

Determinant zero: consistent or not?

  1. |A| = 1224 = 4 − 4 = 0, so there is no unique solution — but that alone does not say which of the other two cases holds.
  2. The left sides are proportional (the second is twice the first), so the second equation would need 2 × 3 = 6 on the right.
