1Objective[1]Heritage 2024–25 First Term, Q1(ii)
Let f : [2, ∞) → ℝ be defined by f(x) = x2 − 4x + 5. Then the range of f is:
  • (a)ℝ
  • (b)[1, ∞)
  • (c)[4, ∞)
  • (d)[5, ∞)
  1. Complete the square: f(x) = (x − 2)2 + 1.
  2. On [2, ∞) the bracket (x − 2) runs over [0, ∞), so (x − 2)2 runs over [0, ∞).
  3. Hence f(x) = (x − 2)2 + 1 takes every value from 1 upwards, and 1 is attained at x = 2.

Note The co-domain is ℝ, but the range is what the function actually reaches. Restricting the domain to [2, ∞) is what makes f one-one here.

Answer [1, ∞)

2Objective[1]Heritage 2024–25 First Term, Q1(vi)
Let A = {x : −1 ≤ x ≤ 1} and f : A → A be defined by f(x) = x|x|. Then f is:
  • (a)a bijection
  • (b)injective but not surjective
  • (c)surjective but not injective
  • (d)neither injective nor surjective
  1. Write f piecewise: f(x) = x2 for x ≥ 0 and f(x) = −x2 for x < 0.
  2. Both branches are strictly increasing, and they meet at f(0) = 0, so f is strictly increasing on the whole of [−1, 1] — hence one-one.
  3. f(−1) = −1 and f(1) = 1, and f is continuous, so by the intermediate value theorem every value in [−1, 1] is taken. f is onto A.

Trap x|x| is not x2. The modulus keeps the sign, which is exactly what makes this one-one where x2 would not be.

Answer a bijection — f is strictly increasing on A and its range is all of A

3Objective[1]Heritage 2024–25 First Term, Q1(xv) · also NCERT Exemplar Ch 1, Q31
A relation R on the set {1, 2, 3} is defined by R = {(1, 2)}. Classify R.
  • (a)reflexive
  • (b)transitive
  • (c)symmetric
  • (d)none of these
  1. Reflexive would need (1,1), (2,2) and (3,3); none is there.
  2. Symmetric would need (2,1) to accompany (1,2); it is not there.
  3. Transitive asks: whenever (a,b) and (b,c) lie in R, does (a,c)? The only pair is (1,2), and there is no pair starting at 2, so the condition is never triggered.

Note A condition that is never triggered is satisfied vacuously. This is the standard trap: a one-element relation is almost always transitive.

Answer transitive (vacuously), but neither reflexive nor symmetric

4Objective[1]NCERT Exemplar Ch 1, Q30
The maximum number of equivalence relations on the set A = {1, 2, 3} is:
  • (a)1
  • (b)2
  • (c)3
  • (d)5

Note An equivalence relation on a set corresponds exactly to a partition of it, so count partitions of a 3-element set.

  1. All separate: {1}{2}{3} — one way.
  2. One pair together: {1,2}{3}, {1,3}{2}, {2,3}{1} — three ways.
  3. All together: {1,2,3} — one way.

5Objective[1]NCERT Exemplar Ch 1, Q53
True or False. Let R = {(3, 1), (1, 3), (3, 3)} be a relation on A = {1, 2, 3}. Then R is symmetric and transitive but not reflexive.

Write True or False, and justify.

  1. Symmetric: (3,1) has its partner (1,3), and (3,3) is its own partner. So R is symmetric.
  2. Reflexive: (1,1) and (2,2) are missing, so R is not reflexive — that part of the claim is right.
  3. Transitive: (1,3) and (3,1) are both in R, so transitivity would need (1,1). It is not there.

Note So the statement fails on transitivity alone. Symmetric and transitive together do not give reflexive — this relation is the standard counter-example.

Answer False — R is symmetric but not transitive, since (1,3), (3,1) ∈ R while (1,1) ≠ R

9Subjective[4]Heritage 2024–25 First Term, Q8
Test whether the relation R on ℤ defined by R = {(a, b) : |a − b| ≤ 5} is reflexive, symmetric and transitive.
  1. Reflexive. |a − a| = 0 ≤ 5 for every integer a, so (a, a) ∈ R. R is reflexive.
  2. Symmetric. |a − b| = |b − a|, so (a, b) ∈ R forces (b, a) ∈ R. R is symmetric.
  3. Transitive. Take a = 1, b = 6, c = 11. Then |1 − 6| = 5 ≤ 5 and |6 − 11| = 5 ≤ 5, so (1,6) and (6,11) lie in R.
  4. But |1 − 11| = 10 > 5, so (1, 11) ≠ R. R is not transitive.

Note One counter-example is enough to kill transitivity, and it must be produced explicitly — saying ‘the gaps can add up’ earns nothing.

Trap A bounded-difference relation is never transitive: differences add, but the bound does not.

Answer Reflexive and symmetric, but not transitive

10Subjective[4]NCERT Exemplar Ch 1, Q20
Let A = ℝ − {3} and B = ℝ − {1}. Let f : A → B be defined by f(x) = x − 2x − 3 for all x ∈ A. Show that f is bijective.
  1. One-one. Suppose f(x1) = f(x2):
    x1 − 2x1 − 3 = x2 − 2x2 − 3
  2. Cross-multiplying and expanding, every quadratic term cancels and what is left is −3x1 − 2x2 = −2x1 − 3x2, i.e. x1 = x2.
  3. Onto. Take any y ∈ B and solve y = x − 2x − 3 for x:
    y(x − 3) = x − 2 ⇒ x(y − 1) = 3y − 2 ⇒ x = 3y − 2y − 1
  4. This x exists for every y ≠ 1, which is exactly the set B, and x ≠ 3 (x = 3 would give 3y − 3 = 3y − 2). So x ∈ A and f(x) = y.

Note The two excluded points are not decoration: 3 is excluded from the domain because f is undefined there, and 1 from the co-domain because x − 2x − 3 → 1 without ever reaching it.

Answer f is one-one and onto, hence bijective, with f−1(y) = 3y − 2y − 1

11Subjective[6]NCERT Exemplar Ch 1, Q23
Let A = {1, 2, 3, …, 9} and let R be the relation on A × A defined by (a, b) R (c, d) if a + d = b + c. Prove that R is an equivalence relation and obtain the equivalence class [(2, 5)].

Note Rewrite the rule first: a + d = b + c is the same as a − b = c − d. So two pairs are related exactly when they have the same difference — and everything follows from that.

  1. Reflexive. a − b = a − b, so (a,b) R (a,b).
  2. Symmetric. If a − b = c − d then c − d = a − b, so (c,d) R (a,b).
  3. Transitive. If a − b = c − d and c − d = e − f then a − b = e − f, so (a,b) R (e,f).
  4. The class. (2,5) has difference 2 − 5 = −3, so [(2,5)] is every pair (a, b) in A × A with a − b = −3, i.e. b = a + 3 with both entries between 1 and 9.

Note a runs from 1 to 6 (a = 7 would need b = 10, outside A), giving six pairs.

Answer [(2, 5)] = {(1,4), (2,5), (3,6), (4,7), (5,8), (6,9)}

23Objective[1]Heritage 2024–25 First Term, Q1(i)
If A and B are symmetric matrices of the same order, then (AB′ − BA′) is a:
  • (a)skew symmetric matrix
  • (b)null matrix
  • (c)symmetric matrix
  • (d)none of these
  1. A and B symmetric means A′ = A and B′ = B, so AB′ − BA′ = AB − BA.
  2. Transpose it: (AB − BA)′ = (AB)′ − (BA)′ = B′A′ − A′B′ = BA − AB.
  3. That is −(AB − BA).

Note So the matrix equals the negative of its own transpose — the definition of skew symmetric. It is the null matrix only in the special case AB = BA, which is not given.

Trap (AB)′ = B′A′, with the order reversed. Keeping the order gives the wrong sign and the wrong answer.

Answer a skew symmetric matrix
