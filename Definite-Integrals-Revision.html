Part 1The definite integral as a limit of a sum

The definition itself. ISC sets it rarely but sets it whole — the four marks are for the construction, not for the arithmetic.

1The definite integral as a limit of a sumISC Specimen 2018, Q7(b)[4]
Evaluate ∫31(x2 + x) dx, expressing it as a limit of a sum.

Worked solution

  1. With a = 1, b = 3 and f(x) = x2 + x, the definition reads
    ∫baf(x) dx = limh→0h [ f(a) + f(a+h) + … + f(a + (n−1)h) ],   nh = b − a
  2. Here nh = 2, so h = 2/n and h → 0 is the same as n → ∞. Write out the general term:
    f(1 + rh) = (1 + rh)2 + (1 + rh) = 2 + 3rh + r2h2
  3. Sum it from r = 0 to n − 1, using ∑r = n(n−1)2 and ∑r2 = (n−1)n(2n−1)6:
    h ∑ f(1 + rh) = 2nh + 3h2·n(n−1)2 + h3·(n−1)n(2n−1)6
  4. Put h = 2/n and let n → ∞. The three terms go to 2·2 = 4, to 32·4 = 6 and to 86·2 = 83:
    I = 4 + 6 + 83 = 383
  5. As a check, the Fundamental Theorem gives [x3/3 + x2/2]13 = 273 + 92 − 13 − 12 = 383. The marks, though, are for the construction.

Note nh = b − a is the whole of the set-up. Students who write h = 1/n out of habit are integrating over a range of length 1 and lose every mark after the first line.

Trap The sum runs r = 0 to n − 1, i.e. n terms starting at f(a) and stopping before f(b). Including f(b) as well adds an (n+1)-th term.

Answer 383

Part 2Straight evaluation: substitution and the standard forms

Change the variable and change the limits with it. Nothing here needs a property; what it needs is not forgetting that t runs between new numbers.

2Straight evaluation: substitution and the standard formsNCERT Exemplar, Chapter 7, Exercise 7.3 Q29
Evaluate ∫101ex + e−x dx.

Worked solution

  1. Multiply numerator and denominator by ex — that is what turns the sum of two exponentials into a quadratic in one:
    I = ∫10exe2x + 1 dx
  2. Put t = ex, so dt = ex dx. Change the limits with the variable: x = 0 gives t = 1, x = 1 gives t = e.
    I = ∫e111 + t2 dt = [ tan−1t ]1e
  3. Hence I = tan−1e − tan−11 = tan−1e − π4 ≈ 0·433.

Note Once the limits are changed there is no going back to x, and no constant of integration to carry. That is the one real advantage a definite integral has over an indefinite one.

Answer tan−1e − π4

3Straight evaluation: substitution and the standard formsNCERT Part II, Chapter 7, Exercise 7.10 Q9
Evaluate ∫20x √2 − x dx.

Worked solution

  1. Put t = 2 − x, so x = 2 − t and dx = −dt. The limits turn over: x = 0 gives t = 2 and x = 2 gives t = 0, and the minus sign from dx turns them back the right way round.
    I = ∫20(2 − t) √t dt
  2. Split and integrate term by term:
    I = ∫20(2t1/2 − t3/2) dt = [ 43t3/2 − 25t5/2 ]02
  3. At t = 2, t3/2 = 2√2 and t5/2 = 4√2, so
    I = 8√23 − 8√25 = 8√2 ( 13 − 15 ) = 16√215

Note This is the reflection property in disguise: t = 2 − x is exactly x → a − x with a = 2. Whichever name you give it, the working is the same.

Answer 16√215

4Straight evaluation: substitution and the standard formsCISCE Competency-Focused Questions, Q95(b)
Find the value of K if ∫π0√π2 − x2 dx = π3K.

Worked solution

  1. This is the standard form ∫√a2 − x2 dx = x2√a2 − x2 + a22 sin−1xa + C, with a = π.
  2. Between 0 and a the first term vanishes at both ends and the second runs from sin−10 = 0 to sin−11 = π2:
    ∫a0√a2 − x2 dx = a22·π2 = πa24
  3. With a = π that is π34, so K = 4.

Note There is nothing to integrate here if you see it: y = √a2 − x2 is the upper half of the circle of radius a, and 0 to a is a quarter of it, i.e. 14πa2.

Answer K = 4

Part 3Splitting the interval: modulus and greatest integer

The integrand changes its formula inside the range, so the integral must be split where it changes. Find the break points first, then integrate each piece with the formula that holds there.

5Splitting the interval: modulus and greatest integerISC Specimen 2023, Q9(i)[4]
Evaluate ∫2−1|x3 − x| dx.

Worked solution

  1. Factorise to find where the sign changes: x3 − x = x(x − 1)(x + 1), which is zero at −1, 0 and 1. Two of those are inside the range, so the integral splits into three pieces.
  2. Testing one point in each: on (−1, 0) it is positive, on (0, 1) negative, on (1, 2) positive.
    I = ∫0−1(x3−x) dx − ∫10(x3−x) dx + ∫21(x3−x) dx
  3. With F(x) = x44 − x22, F(−1) = F(1) = −14, F(0) = 0 and F(2) = 2:
    I = [0 − (−¼)] − [(−¼) − 0] + [2 − (−¼)] = 14 + 14 + 94
  4. So I = 114.

Trap Dropping the modulus and integrating straight through gives F(2) − F(−1) = 2¼, which is smaller than the right answer. An area cannot shrink when you fold part of it above the axis — that is the check to make.

Answer 114

6Splitting the interval: modulus and greatest integerISC Specimen 2024, Q3[2]
Evaluate ∫π/2−π/2|sin x| dx.

Worked solution

  1. |sin x| is an even function — |sin(−x)| = |−sin x| = |sin x| — and the limits are symmetric, so
    I = 2∫π/20|sin x| dx
  2. On [0, π/2] sin x ≥ 0, so the modulus does nothing there:
    I = 2∫π/20sin x dx = 2[ −cos x ]0π/2 = 2(0 + 1) = 2

Note Going even-first is quicker than splitting at 0, and it is the same amount of writing as splitting. Either earns full marks.

Answer 2

7Splitting the interval: modulus and greatest integerISC Specimen 2025, Q3[2]
Evaluate ∫√20[x2] dx, where [·] is the greatest integer function.

Worked solution

  1. Ask what x2 does over the range, not what x does. For 0 ≤ x < 1 we have 0 ≤ x2 < 1, so [x2] = 0. For 1 ≤ x < √2 we have 1 ≤ x2 < 2, so [x2] = 1.
  2. The break point is therefore x = 1, and the integrand is a step function:
    I = ∫100 dx + ∫√211 dx = 0 + [ x ]1√2
  3. So I = √2 − 1.

Note CISCE's own key works it exactly this way, ending “= x|1√2 = √2 −1”.

Trap The break points of [x2] are where x2 crosses an integer, i.e. x = 1, √2, √3 … — not where x does.

Answer √2 − 1

CISCE’s own key∫0√2[x2]dx = ∫010 dx + ∫1√21 dx = x|1√2 = √2 −1

8Splitting the interval: modulus and greatest integerCISCE Competency-Focused Questions, Q107
For any function f(x), ∫baf(x) dx = ∫c1af(x) dx + ∫c2c1f(x) dx + … + ∫bcnf(x) dx, where a < c1 < c2 < … < cn < b. Using this, evaluate ∫20|x2 + 2x − 3| dx.

Worked solution

  1. x2 + 2x − 3 = (x + 3)(x − 1), whose roots are −3 and 1. Only x = 1 lies in [0, 2], so there is exactly one break point — c1 = 1 in the statement quoted.
  2. On [0, 1) the quadratic is negative and on (1, 2] positive:
    I = −∫10(x2+2x−3) dx + ∫21(x2+2x−3) dx
  3. With F(x) = x33 + x2 − 3x: F(0) = 0, F(1) = −53, F(2) = 23.
    I = −(−53 − 0) + ( 23 + 53 ) = 53 + 73 = 4

Note Find the roots first and keep only the ones inside the range. A root outside it — here x = −3 — changes nothing.

Answer 4

Part 4The reflection property

∫ab f(x) dx = ∫ab f(a + b − x) dx. Write the integral a second time with the substitution, add the two, and the awkward denominator cancels. This is the single most-set idea in the whole topic.

9The reflection propertyISC Specimen 2021, Q5(b)[2]
Evaluate ∫π/20sin3/2xsin3/2x + cos3/2x dx.

Worked solution

  1. Call the integral I and apply ∫baf(x) dx = ∫baf(a+b−x) dx with a + b = π/2, which swaps sin and cos:
    I = ∫π/20cos3/2xcos3/2x + sin3/2x dx
  2. Add the two expressions for I. The denominators are the same, so the numerators add to it and cancel:
    2I = ∫π/201 dx = π2
  3. Hence I = π4.

Note The exponent never enters the working. The same two lines give π4 for √sin, for sinn, for tan — for any f at all, provided the denominator is f(sin) + f(cos).

Answer π4

10The reflection propertyISC Specimen 2022 Semester 2, Q1(ii)[1]
If ∫2a0f(x) dx = ∫a0f(x) dx + ∫a0f(k − x) dx, then the value of k is:  (a) a  (b) 2a  (c) independent of a  (d) none of these

Worked solution

  1. Split the left side at a, which is the only thing you are allowed to do for free:
    ∫2a0f(x) dx = ∫a0f(x) dx + ∫2aaf(x) dx
  2. In the second piece put x = 2a − t, so dx = −dt; x = a gives t = a and x = 2a gives t = 0, and the minus sign rights the limits:
    ∫2aaf(x) dx = ∫a0f(2a − t) dt
  3. Comparing with the statement, k = 2a — option (b).

Note This is the property behind “∫2a0f(x) dx = 2∫a0f(x) dx if f(2a − x) = f(x), and 0 if f(2a − x) = −f(x)”. Knowing where that rule comes from is what this one mark is testing.

Answer (b) 2a

11The reflection propertyISC Specimen 2022 Semester 2, Q4[2]
Evaluate ∫82√10 − x√x + √10 − x dx.

Worked solution

  1. Here a = 2 and b = 8, so a + b = 10 and x → 10 − x swaps the two radicals:
    I = ∫82√x√10 − x + √x dx
  2. Add the two:
    2I = ∫821 dx = 8 − 2 = 6
  3. Hence I = 3.

Note Notice that a + b = 10 is exactly the 10 already sitting inside the radical. When a question is built this way — and ISC builds it this way every time — the number under the root tells you which property to reach for.

Answer 3

12The reflection propertyISC Specimen 2022 Semester 2, Q8(b)[6]
Evaluate ∫π/40log(1 + tan x) dx.

Worked solution

  1. a + b = π/4, so replace x by π/4 − x and use tan(π/4 − x) = 1 − tan x1 + tan x:
    I = ∫π/40log ( 1 + 1 − tan x1 + tan x ) dx
  2. The bracket simplifies to 21 + tan x, and log of a quotient splits:
    I = ∫π/40[ log 2 − log(1 + tan x) ] dx = π4 log 2 − I
  3. So 2I = π4 log 2, giving I = π8 log 2.

Note The second integral is the same I, which is why this works. If it is not, you have used the wrong a + b — check the limits before going further.

Trap tan(π/4 − x), not tan(π/2 − x). The upper limit here is π/4; reaching for cot out of habit ruins the cancellation.

Answer π8 log 2

13The reflection propertyISC Specimen 2023, Q5(ii)[2]
Evaluate ∫π/20a sin x + b cos xsin x + cos x dx.

Worked solution

  1. x → π/2 − x interchanges sin and cos throughout:
    I = ∫π/20a cos x + b sin xcos x + sin x dx
  2. Add. The numerators become (a + b)(sin x + cos x), which cancels the denominator entirely:
    2I = ∫π/20(a + b) dx = (a + b)π2
  3. Hence I = (a + b)π4.

Note Setting a = b = 1 gives I = π4, which is the same answer as the sin3/2 problem — a free check that the algebra went through.

Answer (a + b)π4

14The reflection propertyISC Specimen 2026, Q5(ii)[2]
Evaluate ∫50√x√5 − x + √x dx.

Worked solution

  1. a + b = 5, and x → 5 − x swaps the two radicals:
    I = ∫50√5 − x√x + √5 − x dx
  2. Adding the two forms:
    2I = ∫501 dx = [ x ]05 = 5
  3. Hence I = 52.

Note CISCE's key runs 2I = ∫501 dx = [x]05 and stops there. The answer of any integral of this shape is always half the length of the interval.

15The reflection propertyISC Specimen 2026, Q12(ii)[6]
Evaluate ∫3π/4π/4x1 + sin x dx.

Worked solution

  1. a + b = π/4 + 3π/4 = π, and sin(π − x) = sin x, so only the numerator changes:
    I = ∫3π/4π/4π − x1 + sin x dx
  2. Add the two. The x cancels and π comes outside:
    2I = π ∫3π/4π/411 + sin x dx
  3. Rationalise: multiply above and below by 1 − sin x, so the denominator becomes cos2x.
    ∫1 − sin xcos2x dx = ∫(sec2x − sec x tan x) dx = tan x − sec x
  4. At 3π/4: tan = −1, sec = −√2, giving √2 − 1. At π/4: 1 − √2. The difference is 2√2 − 2.
    2I = π(2√2 − 2)  ⇒  I = π(√2 − 1)

Note I ≈ 1·301. The substitution t = tan(x/2) also works but takes three times as long and runs into a singular limit.

Trap It is tempting to write the reflection as x → π/2 − x. The property uses a + b, which here is π, not the length of the interval.

Answer π(√2 − 1)

16The reflection propertyNCERT Exemplar, Chapter 7, Exercise 7.3 Q46
Evaluate ∫π0x log sin x dx.

Worked solution

  1. Apply x → π − x. Since sin(π − x) = sin x, only the factor x changes:
    I = ∫π0(π − x) log sin x dx = π ∫π0log sin x dx − I
  2. So 2I = π ∫π0log sin x dx, and log sin x is symmetric about π/2, so that integral is 2∫π/20log sin x dx.
  3. The standard value. Let J = ∫π/20log sin x dx. By x → π/2 − x it also equals ∫π/20log cos x dx, so
    2J = ∫π/20log(sin x cos x) dx = ∫π/20log sin 2x2 dx
  4. Putting 2x = t in ∫π/20log sin 2x dx turns it into 12∫π0log sin t dt = J. Hence 2J = J − π2 log 2, i.e. J = −π2 log 2.
  5. Therefore 2I = π·2J = −π2 log 2, and
    I = −π22 log 2

Note I ≈ −3·421. J = −(π/2) log 2 is worth memorising outright — it turns up in the NCERT exercise, in the Exemplar and in two ISC specimen papers.

Answer −π22 log 2

17The reflection propertyNCERT Part II, Chapter 7, Exercise 7.10 Q10
Evaluate ∫π/20(2 log sin x − log sin 2x) dx.

Worked solution

  1. Open the second logarithm first — nothing else can be done until sin 2x is gone:
    log sin 2x = log(2 sin x cos x) = log 2 + log sin x + log cos x
  2. So the integrand is 2 log sin x − log 2 − log sin x − log cos x = log sin x − log cos x − log 2.
    I = ∫π/20log sin x dx − ∫π/20log cos x dx − π2 log 2
  3. By x → π/2 − x the first two integrals are equal, so they cancel:
    I = −π2 log 2

Note Neither integral had to be evaluated. That is the point of the question — the examiner is testing whether you reach for the symmetry before reaching for the value of ∫π/20log sin x dx.

Answer −π2 log 2

18The reflection propertyNCERT Part II, Chapter 7, Exercise 7.10 Q21
The value of ∫π/20log 4 + 3 sin x4 + 3 cos x dx is:  (A) 2  (B) 34  (C) 0  (D) −2

Worked solution

  1. Apply x → π/2 − x. Sine and cosine change places, so the fraction turns upside down:
    I = ∫π/20log 4 + 3 cos x4 + 3 sin x dx = −∫π/20log 4 + 3 sin x4 + 3 cos x dx = −I
  2. So 2I = 0, i.e. I = 0 — option (C).

Note log(1/u) = −log u is the whole trick. Any integrand of the form log[f(sin x)/f(cos x)] over 0 to π/2 integrates to zero, whatever f is.

Answer (C) 0

Part 5Odd, even and symmetric limits

Over −a to a, an odd integrand gives 0 and an even one gives twice the half-range integral. The 1/(1 + ex) family looks harder than it is and reduces to the same thing.

19Odd, even and symmetric limitsISC Specimen 2021, Q12(b)[6]
Evaluate ∫π/2−π/2cos x1 + ex dx.

Worked solution

  1. The integrand is neither odd nor even, but the limits are symmetric, so apply x → −x:
    I = ∫π/2−π/2cos x1 + e−x dx = ∫π/2−π/2ex cos x1 + ex dx
  2. Add the two. The denominators are the same and the numerators add to (1 + ex) cos x, which cancels it:
    2I = ∫π/2−π/2cos x dx = 2∫π/20cos x dx = 2
  3. Hence I = 1.

Note The general result is worth carrying: over −a to a, ∫a−af(x)1 + ex dx = ∫a0f(x) dx whenever f is even. Here f = cos and a = π/2, so the answer is ∫π/20cos x dx = 1 in one line.

Answer 1

20Odd, even and symmetric limitsISC Specimen 2025, Q12(ii)[6]
Evaluate ∫π0(sin4x + cos4x) dx. Hence evaluate ∫2π−2πsin4x + cos4x1 + ex dx.

Worked solution

  1. First part. Reduce the fourth powers before integrating:
    sin4x + cos4x = 1 − 2sin2x cos2x = 1 − 12sin22x = 34 + 14cos 4x
  2. Integrating from 0 to π, the cos 4x term contributes [sin 4x / 16] = 0:
    ∫π0(sin4x + cos4x) dx = 34π
  3. Second part. f(x) = sin4x + cos4x is even, and the limits −2π to 2π are symmetric, so the 1 + ex collapses exactly as in the previous problem:
    ∫a−af(x)1 + ex dx = ∫a0f(x) dx  with a = 2π
  4. And over 0 to 2π the cos 4x term again integrates to zero:
    ∫2π0( 34 + 14cos 4x ) dx = 34·2π = 3π2

Note “Hence” is an instruction, not a courtesy: the first part is there to give you 34 + 14cos 4x, which is what makes the second part one line.

Trap The second answer is not half the first scaled up by 4. Do the reduction to ∫2π0f dx and integrate over the new range; 0 to 2π is twice 0 to π, so the answer is 2 × 3π4 = 3π2.

Answer ∫π0(sin4x + cos4x) dx = 3π4,  and the second integral = 3π2

21Odd, even and symmetric limitsISC Specimen 2027, Q1(xvii)[1]
Assertion: ∫1−1x3 cos x dx = 0.
Reason: If f(x) is a continuous function defined on [0, a], then ∫a0f(x) dx = ∫a0f(a − x) dx.
Which one is correct?  (a) Both true, Reason is the correct explanation  (b) Both true, Reason is not the correct explanation  (c) Assertion true, Reason false  (d) Assertion false, Reason true

Worked solution

  1. The Assertion. g(x) = x3 cos x has g(−x) = (−x)3cos(−x) = −x3cos x = −g(x), so g is odd; over the symmetric limits −1 to 1 an odd integrand gives 0. The Assertion is true.
  2. The Reason. ∫a0f(x) dx = ∫a0f(a−x) dx is a correct statement of the reflection property. The Reason is true.
  3. But does it explain the Assertion? No. The Reason is about the interval [0, a]; the Assertion is about [−a, a], and the property that settles it is ∫a−af dx = 0 for f odd — a different rule.
  4. So the answer is (b): both true, Reason not the correct explanation.

Note CISCE's published key gives (b). In an assertion–reason question a true reason still scores nothing unless it is the reason for that assertion — read the interval, not just the formula.

Answer (b) Both Assertion and Reason are true, but Reason is not the correct explanation

CISCE’s own key(b) Both Assertion and Reason are true, but Reason is not the correct explanation of Assertion.

22Odd, even and symmetric limitsCISCE Competency-Focused Questions, Q12
Identify the correct value of ∫π0sin2024x cos2023x dx.

Worked solution

  1. Do not touch the exponents. Apply x → π − x: sin(π−x) = sin x is unchanged, but cos(π−x) = −cos x, and the power 2023 is odd, so that factor flips sign.
    I = ∫π0sin2024x (−cos x)2023 dx = −I
  2. Hence 2I = 0, i.e. I = 0.

Note What matters is only that the cosine power is odd and the sine power does not care. Replace 2024 and 2023 by any even and odd numbers and the answer is still 0.

Trap Over 0 to π — not over 0 to π/2, where the same integrand gives 12024 and nothing cancels.

Answer 0

23Odd, even and symmetric limitsCISCE Competency-Focused Questions, Q33
Statement I: ∫2−2x21 + 2x dx = 83.
Statement II: ∫a−af(x) dx = 2∫a0f(x) dx, if f(x) is an even function.
Which of the statements is true?

Worked solution

  1. Test Statement I. The integrand is not even, so apply x → −x:
    I = ∫2−2x21 + 2−x dx = ∫2−22xx21 + 2x dx
  2. Add the two and the denominator cancels:
    2I = ∫2−2x2 dx
  3. Now Statement II applies, because x2 is even:
    2I = 2∫20x2 dx = 2·83  ⇒  I = 83
  4. So both statements are true, and Statement II is exactly the step that finishes Statement I.

Trap Statement II cannot be applied to the original integrand — x2/(1 + 2x) is not even. Doing so gives 2∫02, which is wrong. The symmetry has to be used to produce an even integrand first.

Answer Both statements are true; Statement II is what completes the proof of Statement I (the integral is 83)

24Odd, even and symmetric limitsCISCE Competency-Focused Questions, Q56
Evaluate ∫π/2−π/2sin|x| dx.

Worked solution

  1. |−x| = |x|, so sin|x| is even; with symmetric limits,
    I = 2∫π/20sin|x| dx
  2. On [0, π/2] we have |x| = x, so the modulus disappears:
    I = 2∫π/20sin x dx = 2[−cos x]0π/2 = 2

Note sin|x| is even; |sin x| is also even; sin x on its own is odd. Reading which one is on the page is most of this question.

Trap sin|x| is not |sin x| in general — they agree only where sin x ≥ 0. Over −π to π the two integrals differ.

Answer 2

25Odd, even and symmetric limitsNCERT Exemplar, Chapter 7, Exercise 7.3 Q57
∫π/4−π/411 + cos 2x dx is equal to:  (A) 1  (B) 2  (C) 3  (D) 4

Worked solution

  1. Use the double-angle identity before anything else: 1 + cos 2x = 2cos2x.
    I = 12∫π/4−π/4sec2x dx
  2. The integrand is even, so
    I = 12[ tan x ]−π/4π/4 = 12(1 − (−1)) = 1
  3. So the answer is (A) 1.

Note sec2x has no trouble anywhere on [−π/4, π/4]; the denominator 1 + cos 2x would only vanish at x = ±π/2, outside the range.

Answer (A) 1

Part 6Additivity, and the integral as an area

∫ab = ∫ac + ∫cb, and ∫ba = −∫ab. These are the questions that give you one integral and ask for another.

26Additivity, and the integral as an areaISC Specimen 2027, Q14[3]
Let ∫513f(x) dx = 12.
(i) Show that ∫15f(x) dx = −4.
(ii) Find the value of ∫21(x + f(x)) dx + ∫52(x + f(x)) dx.

Worked solution

  1. (i) A constant comes straight out: ∫513f(x) dx = 3∫51f(x) dx = 12, so ∫51f(x) dx = 4.
    ∫15f(x) dx = −∫51f(x) dx = −4   [ ∫baf dx = −∫abf dx ]
  2. (ii) The two ranges are adjacent, so they join into one:
    ∫21(x + f) dx + ∫52(x + f) dx = ∫51(x + f) dx
  3. Split off the part you can integrate:
    ∫51x dx + ∫51f(x) dx = [ x22 ]15 + 4 = ( 252 − 12 ) + 4 = 12 + 4
  4. So the value is 16.

Note f is never given, and never needs to be. Every definite-integral question of this shape is answered from the three rules alone: constants come out, adjacent ranges join, and reversing the limits changes the sign.

Answer (i) −4   (ii) 16

27Additivity, and the integral as an areaISC Specimen 2025, Q18[4]
(i) Sketch the region bounded by the curve y = x|x| and the ordinates x = −1 and x = 1. (ii) Evaluate ∫10x2 dx. (iii) Hence find the area of that region.

Worked solution

  1. (i) Split the modulus:
    y = x|x| = {−x2,x < 0x2,x ≥ 0
  2. So the curve is the right half of y = x2 joined to the left half of y = −x2; it is odd, and passes through the origin with zero gradient.
  3. (ii) ∫10x2 dx = [ x3/3 ]01 = 13.
  4. (iii) The piece from 0 to 1 has area 13. The piece from −1 to 0 lies below the axis, so its integral is −13 while its area is 13.
    Area = 13 + 13 = 2∫10x2 dx = 23 sq. units

Trap Integrating y from −1 to 1 straight through gives 0, because the function is odd. Zero is the right value of the integral and the wrong value of the area; area questions want the modulus, or symmetry as used here.

The figure shows the line x + 2y = 8, and the region bounded by that line, the x-axis and the ordinate x = 2 is shaded. The expression for finding the area of the shaded region is:
 (a) ∫82(4 − x2 − 2) dx  (b) ∫82(x2 + 4) dx  (c) ∫82(y2 + 4) dy  (d) ∫82(4 − x2) dx

Worked solution

  1. Put the line in the form the strip needs — y as a function of x:
    x + 2y = 8  ⇒  x8 + y4 = 1  ⇒  y = 4 − x2
  2. A vertical strip at x runs from the x-axis (y = 0) up to the line, so its height is 4 − x/2 — the top curve minus the bottom one, and the bottom one is 0, not 2.
  3. The strip starts at the given ordinate x = 2 and ends where the line meets the axis, y = 0 ⇒ x = 8.
    Area = ∫82( 4 − x2 ) dx
  4. So the answer is (d). (Its value, had the question asked, is 9 square units.)

Note CISCE's key sets out exactly this: convert to intercept form, read off y = 4 − x/2, then state the integral.

Trap Option (a) subtracts 2 as though the strip started at the height y = 2. x = 2 is a vertical line, not a horizontal one — it fixes the lower limit, not the lower boundary.

29Additivity, and the integral as an areaCISCE Competency-Focused Questions, Q116
Find the area of the region bounded by the x-axis, part of the curve y = 1 + 8x2, and the ordinates x = 2 and x = 4. If the ordinate at x = a divides that area into two equal parts, find a.

Worked solution

  1. The curve is above the axis throughout [2, 4], so the area is the integral itself:
    A = ∫42( 1 + 8x2 ) dx = [ x − 8x ]24
  2. At x = 4 that is 4 − 2 = 2; at x = 2 it is 2 − 4 = −2.
    A = 2 − (−2) = 4 sq. units
  3. For the second part, the left piece must be half of it:
    ∫a2( 1 + 8x2 ) dx = 2  ⇒  ( a − 8a ) − (−2) = 2
  4. So a − 8a = 0, giving a2 = 8 and a = 2√2 (the negative root is outside [2, 4]).

Note 2√2 ≈ 2·83, left of the midpoint 3 — which is right, because the curve is falling, so the left strip is the taller one and needs less width to hold the same area.

Trap ∫8x−2dx = −8/x. Losing that minus sign turns the area into 2 − 4 = −2 — and a negative area should always send you back to the antiderivative.

Answer Area = 4 sq. units;  a = 2√2
