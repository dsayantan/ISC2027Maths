1. Relations and Functions

Four questions, and between them they test every definition in the chapter. Nothing here needs calculation — it is all about stating a definition precisely and then checking it.

1.1The three properties, with their quantifiers

Reflexive: (a, a) ∈ R for every a in the set. Symmetric: whenever (a, b) ∈ R, also (b, a) ∈ R. Transitive: whenever (a, b) and (b, c) are both in R, so is (a, c).

Watch outReflexive needs every element, so one missing pair kills it. Symmetric and transitive are conditional — they only ask for something when the premise holds.

Needed forFT Q1(xv) FT Q8

1.2Vacuous truth

If a relation contains no pair (a, b) and (b, c) to trigger transitivity, the condition is satisfied vacuously and the relation is transitive.

Watch outThis is the commonest one-mark trap in the chapter. R = {(1, 2)} is transitive; R = {(2, 2)} is symmetric and transitive.

Needed forFT Q1(xv) CISCE competency booklet, Q28

1.3Equivalence relation and its classes

All three properties together. The classes partition the set, and two elements are in the same class exactly when they are related.

Watch outA parity condition is transitive; a bounded-difference condition such as |a − b| ≤ 5 is not — differences add but the bound does not.

Needed forFT Q8 NCERT Part I, Chapter 1

1.4One-one, onto, bijection — how each is proved

One-one: assume f(x1) = f(x2) and derive x1 = x2. Onto: take any y in the co-domain and solve y = f(x) for an x in the domain.

Needed forFT Q1(vi) NCERT Exemplar Ch 1, Q21(iii)

1.5Strictly increasing ⇒ one-one

If f is strictly increasing (or strictly decreasing) on an interval it is automatically one-one there. With continuity, the intermediate value theorem then makes it onto its range.

Watch outx|x| is strictly increasing across 0 because the modulus keeps the sign; x2 is not.

Needed forFT Q1(vi)

1.6Range against co-domain

The co-domain is where the function is declared to land; the range is what it actually reaches. A question asking for the range wants the second.

Needed forFT Q1(ii) NCERT Exemplar Ch 1, Q14

1.7Finding a range by completing the square

f(x) = x2 − 4x + 5 = (x − 2)2 + 1. On a restricted domain, read off what the bracket can do and push it through.

Watch outThe restriction to [2, ∞) is what makes the function one-one; without it the same formula is many-one.

Needed forFT Q1(ii)

3. Matrices

Four questions: one on transposes, one decomposition, and two systems of equations solved by the inverse.

3.1Transpose rules

(A′)′ = A, (A + B)′ = A′ + B′, and — the one that matters — (AB)′ = B′A′, with the order reversed.

Watch outKeeping the order gives the wrong sign and therefore the wrong answer.

Needed forFT Q1(i) NCERT Exemplar Ch 3, Q63

3.2Symmetric and skew symmetric

A′ = A is symmetric; A′ = −A is skew. A skew matrix always has a zero diagonal, because aii = −aii.

Watch outThe zero diagonal is the quickest check that an answer is right.

4. Determinants

Four questions, none of which should be expanded by brute force. Every one is a properties question.

4.1The properties worth knowing by name

  • A common factor in a row or column comes out.
  • Two identical — or proportional — rows or columns make it zero.
  • Ri → Ri + kRj leaves the value unchanged.
  • Interchanging two rows changes the sign.

9. Linear Programming

Five questions — and the two long ones are the same diet problem, set eight years apart with the grains and prices exchanged. Formulation is most of the marks.

9.1Formulating

  1. Name the variables, with their units.
  2. One inequality per resource or requirement.
  3. Write the objective, and say whether it is to be maximised or minimised.
  4. Add x, y ≥ 0.

Watch outConvert the units first. Costs quoted per kg against contents quoted per gram is exactly where these questions catch people.

Needed forFT Q22 PB Q13(b) NCERT Exemplar Ch 12, Q23

9.2Half planes, strict and non-strict

A linear inequality is a half plane. A strict one (<) excludes its boundary; test the origin to see which side is meant.

Needed forFT Q19(ii) NCERT Exemplar Ch 12

9.3The corner point theorem

On a bounded feasible region the optimum of a linear objective is attained at a corner point. Evaluate Z at each and compare.

Needed forFT Q19(v) FT Q20 NCERT Exemplar Ch 12, Q1 NCERT Exemplar Ch 12, Q10

9.4Unbounded regions need one more check

If the region is unbounded, a corner value M is the minimum only if the open half plane ax + by < M has no point in common with the region.

Watch outQuoting the smallest corner value without this check is an incomplete answer — a minimum need not exist at all.

Needed forFT Q22 PB Q13(b)

9.5Ties between two corners

If Z takes the same value at two corner points, the objective line is parallel to that edge and every point of the edge is optimal.

Needed forFT Q19(v) NCERT Exemplar Ch 12, Q22

9.6Feasible solutions against the optimal solution

Every point of the region is a feasible solution — so there are usually infinitely many. Only the optimum is confined to the corners.

Watch outFT Q20 asks for the number of feasible solutions, not the maximum. The answer is ‘infinite’.

Needed forFT Q20

FT Q1(xv) — Heritage 2024–25 First Term

FT Q1(xv)Heritage 2024–25 First Term
A relation R on the set {1, 2, 3} is defined by R = {(1, 2)}. Classify R.
  • (a)reflexive
  • (b)transitive
  • (c)symmetric
  • (d)none of these

Solution

  1. Reflexive would need (1,1), (2,2) and (3,3); none is there.
  2. Symmetric would need (2,1) to accompany (1,2); it is not there.
  3. Transitive asks: whenever (a,b) and (b,c) lie in R, does (a,c)? The only pair is (1,2), and there is no pair starting at 2, so the condition is never triggered.

Note A condition that is never triggered is satisfied vacuously. This is the standard trap: a one-element relation is almost always transitive.

Answer transitive (vacuously), but neither reflexive nor symmetric

FT Q8 — Heritage 2024–25 First Term

FT Q8Heritage 2024–25 First Term
Test whether the relation R on ℤ defined by R = {(a, b) : |a − b| ≤ 5} is reflexive, symmetric and transitive.

Solution

  1. Reflexive. |a − a| = 0 ≤ 5 for every integer a, so (a, a) ∈ R. R is reflexive.
  2. Symmetric. |a − b| = |b − a|, so (a, b) ∈ R forces (b, a) ∈ R. R is symmetric.
  3. Transitive. Take a = 1, b = 6, c = 11. Then |1 − 6| = 5 ≤ 5 and |6 − 11| = 5 ≤ 5, so (1,6) and (6,11) lie in R.
  4. But |1 − 11| = 10 > 5, so (1, 11) ≠ R. R is not transitive.

Note One counter-example is enough to kill transitivity, and it must be produced explicitly — saying ‘the gaps can add up’ earns nothing.

Trap A bounded-difference relation is never transitive: differences add, but the bound does not.

Answer Reflexive and symmetric, but not transitive

Show that R = {(a, b) : |a − b| is even} on {1, 2, 3, 4, 5} is an equivalence relation.

Solution

FT Q1(vi) — Heritage 2024–25 First Term

FT Q1(vi)Heritage 2024–25 First Term
Let A = {x : −1 ≤ x ≤ 1} and f : A → A be defined by f(x) = x|x|. Then f is:
  • (a)a bijection
  • (b)injective but not surjective
  • (c)surjective but not injective
  • (d)neither injective nor surjective

Solution

  1. Write f piecewise: f(x) = x2 for x ≥ 0 and f(x) = −x2 for x < 0.
  2. Both branches are strictly increasing, and they meet at f(0) = 0, so f is strictly increasing on the whole of [−1, 1] — hence one-one.
  3. f(−1) = −1 and f(1) = 1, and f is continuous, so by the intermediate value theorem every value in [−1, 1] is taken. f is onto A.

Trap x|x| is not x2. The modulus keeps the sign, which is exactly what makes this one-one where x2 would not be.

Answer a bijection — f is strictly increasing on A and its range is all of A

FT Q1(ii) — Heritage 2024–25 First Term

FT Q1(ii)Heritage 2024–25 First Term
Let f : [2, ∞) → ℝ be defined by f(x) = x2 − 4x + 5. Then the range of f is:
  • (a)ℝ
  • (b)[1, ∞)
  • (c)[4, ∞)
  • (d)[5, ∞)

Solution

  1. Complete the square: f(x) = (x − 2)2 + 1.
  2. On [2, ∞) the bracket (x − 2) runs over [0, ∞), so (x − 2)2 runs over [0, ∞).

Note The co-domain is ℝ, but the range is what the function actually reaches. Restricting the domain to [2, ∞) is what makes f one-one here.

Answer [1, ∞)

Solution

FT Q22Heritage 2024–25 First Term
Every gram of rice provides 0·1 g of protein and 0·25 g of carbohydrates; for wheat the values are 0·05 g and 0·5 g. Rice costs ₹40 per kg and wheat ₹60 per kg. The minimum daily requirements are 50 g of protein and 200 g of carbohydrates. In what quantities should they be mixed to meet the requirements at least cost? Formulate and solve graphically.

Solution

  1. Formulation. Let the diet contain x g of rice and y g of wheat.
    Protein: 0·1x + 0·05y ≥ 50 ⇒ 2x + y ≥ 1000
    Carbohydrate: 0·25x + 0·5y ≥ 200 ⇒ x + 2y ≥ 800
  2. Cost in rupees (₹40 per 1000 g is ₹0·04 per gram): minimise C = 0·04x + 0·06y, with x, y ≥ 0.
  3. Corner points. The region is unbounded, above both lines. 2x + y = 1000 meets the y-axis at (0, 1000); x + 2y = 800 meets the x-axis at (800, 0).
  4. The two lines cross where y = 1000 − 2x gives x + 2000 − 4x = 800, so x = 400 and y = 200.
  5. C(0, 1000) = ₹60; C(800, 0) = ₹32; C(400, 200) = 16 + 12 = ₹28.
  6. Unbounded check. The smallest corner value is 28; the open half plane 0·04x + 0·06y < 28 has no point in common with the feasible region, so 28 really is the minimum.

Note 400 g of rice and 200 g of wheat — check the requirements: protein 40 + 10 = 50 g ✓, carbohydrate 100 + 100 = 200 g ✓. Both bind exactly, which is why this corner is optimal.

Trap An unbounded feasible region needs that last check. Quoting the smallest corner value without it is incomplete, because a minimum need not exist.

Answer 400 g of rice and 200 g of wheat, at a minimum cost of ₹28

FT Q19(v)Heritage 2024–25 First Term
The corner points of the feasible region determined by a system of linear constraints are (0, 3), (1, 1) and (3, 0). Let Z = px + qy with p, q > 0. Find the condition on p and q for the minimum of Z to occur at both (3, 0) and (1, 1).
  • (a)q = 2p
  • (b)p = 2q
  • (c)p = q
  • (d)p = 3q

Solution

  1. If the minimum occurs at two corner points, Z takes the same value at both.
  2. Z(3, 0) = 3p and Z(1, 1) = p + q.
  3. Setting them equal: 3p = p + q, so q = 2p.

Note When two corner points tie, every point on the segment joining them is also optimal — the objective line is parallel to that edge, and the problem has infinitely many optimal solutions.

Answer q = 2p
