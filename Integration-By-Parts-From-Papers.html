What the list tells you about how ISC sets this topic

  • It is worth 1 to 6 marks and appears in most years — 17 problems across 23 papers. Never skip it.
  • Inverse trigonometric integrands dominate. Five of the thirteen classic problems have tan−1 in them, and ∫tan−1√x dx is set twice — Board 2018 Q7 and Specimen 2021 Q12(a), identical, for 4 marks and then 6.
  • Logarithms are the other half. ∫log x dx in four different disguises: log10x, log 2x, ln x and (log x)2.
  • Learn the ex(f + f′) result cold. Four of the seventeen are that one identity, and every one of them is a 1–2 mark question you should finish in under a minute.
  • Simplify before you reach for parts. Two problems here (Board 2020 Q13(a), Specimen 2027 Q18(i)(b)) only need parts after a simplification or substitution, and six more look like parts but are not — see the last section.

Classic integration by parts

∫u dv = uv − ∫v du, choosing u by ILATE: Inverse, Logarithmic, Algebraic, Trigonometric, Exponential — whichever comes first is u.

1 ISC Board 2018Question 7 4 marks
∫tan−1√x dx

NoteSet again, word for word, as Specimen 2021 Q12(a) — the most repeated by-parts question in the collection.

  1. Take u = tan−1√x and dv = dx, so v = x and
    du = 11 + x · 12√x dx = dx2√x(1 + x)
  2. Applying ∫u dv = uv − ∫v du:
    I = x tan−1√x − 12 ∫√x1 + x dx
  3. For the remaining integral put t = √x, so x = t2 and dx = 2t dt:
    ∫√x1 + x dx = ∫2t21 + t2 dt = 2∫(1 − 11 + t2) dt = 2t − 2 tan−1t
  4. That is 2√x − 2 tan−1√x. Substituting back,
    I = x tan−1√x − 12(2√x − 2 tan−1√x)

Answer(x + 1) tan−1√x − √x + C

2 ISC Board 2020Question 13(a) 6 marks
∫tan−11 − x1 + x dx

NoteThe marks are for spotting the simplification. Going straight to parts on the original integrand is far messier.

  1. Simplify first. Using tan−1a − tan−1b = tan−1a − b1 + ab with a = 1:
    tan−11 − x1 + x = tan−11 − tan−1x = π4 − tan−1x  (x > −1)
  2. So I = πx4 − J, where J = ∫tan−1x dx.
  3. Now parts on J only. u = tan−1x, dv = dx, v = x:
    J = x tan−1x − ∫x1 + x2 dx = x tan−1x − 12 log(1 + x2)
  4. Therefore I = πx4 − x tan−1x + 12 log(1 + x2).

Answerπx4 − x tan−1x + 12 log(1 + x2) + C

3 ISC Board 2024Question 9(i) 4 marks
∫x2 cos x dx

NoteThe standard two-application case. Keep the sign of v straight: ∫cos x dx = sin x but ∫sin x dx = −cos x.

  1. ILATE puts the algebraic factor first: u = x2, dv = cos x dx, v = sin x.
    I = x2 sin x − ∫2x sin x dx
  2. Apply parts a second time to ∫2x sin x dx, with u = 2x, dv = sin x dx, v = −cos x:
    ∫2x sin x dx = −2x cos x + ∫2 cos x dx = −2x cos x + 2 sin x
  3. Substituting back:
    I = x2 sin x − (−2x cos x + 2 sin x)

Answerx2 sin x + 2x cos x − 2 sin x + C

4 ISC Board 2025Question 8(ii) 4 marks
∫(log x)2 dx

NoteThere is no second factor, so take dv = dx. The same trick handles ∫log x dx, ∫sin−1x dx and ∫tan−1x dx.

  1. Write the integrand as (log x)2 · 1 and take u = (log x)2, dv = dx, v = x. Then du = 2 log x · 1x dx.
    I = x(log x)2 − ∫x · 2 log x · 1x dx = x(log x)2 − 2∫log x dx
  2. Parts again on ∫log x dx, with u = log x, dv = dx, v = x:
    ∫log x dx = x log x − ∫x · 1x dx = x log x − x
  3. Therefore I = x(log x)2 − 2(x log x − x).

Answerx[(log x)2 − 2 log x + 2] + C

5 ISC Board 2025 ImprovementQuestion 9(i) 4 marks
∫x tan−1x dx

NoteILATE overrides the instinct to take u = x: the Inverse function comes first.

  1. u = tan−1x, dv = x dx, so v = x22 and du = dx1 + x2.
    I = x22 tan−1x − 12 ∫x21 + x2 dx
  2. The remaining integrand is improper, so divide before integrating:
    x21 + x2 = 1 − 11 + x2  ⇒  ∫x21 + x2 dx = x − tan−1x
  3. Hence I = x22 tan−1x − 12(x − tan−1x).

Answerx22 tan−1x − x2 + 12 tan−1x + C

6 ISC Specimen 2021Question 12(a) 6 marks
∫tan−1√x dx

NoteThe same integral as Board 2018 Q7, three years earlier and worth 6 marks instead of 4. Solution identical — see problem 1.

  1. u = tan−1√x, dv = dx, v = x, du = dx2√x(1 + x).
    I = x tan−1√x − 12 ∫√x1 + x dx
  2. With t = √x (so x = t2, dx = 2t dt) the remaining integral is 2t − 2 tan−1t = 2√x − 2 tan−1√x.

Answer(x + 1) tan−1√x − √x + C

7 ISC Specimen 2022, Semester 2Question 2(b) 2 marks
∫log10 x dx

NoteChange the base before doing anything else — parts works on the natural logarithm.

  1. Change of base: log10 x = log xlog 10, and 1log 10 is a constant.
    I = 1log 10 ∫log x dx
  2. Parts with u = log x, dv = dx, v = x:
    ∫log x dx = x log x − ∫x · 1x dx = x log x − x

Answerx(log x − 1)log 10 + C

8 ISC Specimen 2023Question 1(xiii) 1 mark
∫log 2x dx = x log 2x − k + C  — find k

NoteA one-mark question that only asks for the second term of the by-parts formula.

  1. u = log 2x, dv = dx, v = x. Note du = 12x · 2 dx = dxx.
    I = x log 2x − ∫x · 1x dx = x log 2x − ∫1 dx
  2. So the subtracted term is simply x.

Answerk = x  (so I = x log 2x − x + C)

9 ISC Specimen 2023Question 5(i) 2 marks
∫[sin(log x) + cos(log x)] dx

NoteOne of a family in which the second term is produced, and cancelled, by the by-parts step on the first.

  1. Work on I1 = ∫sin(log x) dx with u = sin(log x), dv = dx, v = x:
    I1 = x sin(log x) − ∫x · cos(log x) · 1x dx = x sin(log x) − ∫cos(log x) dx
  2. The original integral is I1 + ∫cos(log x) dx, so the two remaining integrals cancel exactly:
    I = x sin(log x) − ∫cos(log x) dx + ∫cos(log x) dx = x sin(log x)
  3. Check by differentiating: ddx[x sin(log x)] = sin(log x) + cos(log x). ✓

Answerx sin(log x) + C

10 ISC Specimen 2024Question 5(ii) 2 marks
∫x ex dx

NoteThe textbook case, and the one to do first if you are relearning the method. From 2024-v2.pdf — see the note on the duplicate file below.

  1. ILATE: Algebraic before Exponential, so u = x, dv = ex dx, v = ex.
    I = x ex − ∫ex dx = x ex − ex

Answer(x − 1)ex + C

11 ISC Specimen 2027Question 18(i)(a) 2 marks
∫ln x dx

NoteDeliberately the first half of a two-part question — part (b) below reduces to exactly this.

  1. Write ln x = ln x · 1 and take u = ln x, dv = dx, v = x.
    I = x ln x − ∫x · 1x dx = x ln x − x

Answerx(ln x − 1) + C

12 ISC Specimen 2027Question 18(i)(b) 3 marks
∫ln[ln(1 + x1 − x)]1 − x2 dx

NoteThe word hence in the question is the instruction: substitute so that part (a) finishes it.

  1. Put t = ln1 + x1 − x = ln(1 + x) − ln(1 − x). Then
    dtdx = 11 + x + 11 − x = 21 − x2  ⇒  dx1 − x2 = dt2
  2. The integral becomes, in t alone,
    I = 12 ∫ln t dt
  3. which is part (a) with x replaced by t: 12 t(ln t − 1).

Answer12 t(ln t − 1) + C,  where t = ln1 + x1 − x

13 Heritage School Pre-Board 2016–17Question 1(e) 3 marks
∫x − sin x1 − cos x dx

NoteThe prettiest one here: the integral thrown out by the by-parts step cancels the other half of the integrand exactly, leaving a one-term answer.

  1. Half-angle identities first: 1 − cos x = 2 sin2(x/2) and sin x = 2 sin(x/2) cos(x/2). So
    x − sin x1 − cos x = x2 sin2(x/2) − cos(x/2)sin(x/2) = 12 x cosec2(x/2) − cot(x/2)
  2. Parts on the first piece only, with u = x and dv = 12 cosec2(x/2) dx, so v = −cot(x/2):
    12 ∫x cosec2(x/2) dx = −x cot(x/2) + ∫cot(x/2) dx
  3. Now subtract the second piece of the integrand:
    I = [−x cot(x/2) + ∫cot(x/2) dx] − ∫cot(x/2) dx = −x cot(x/2)
  4. The two cotangent integrals cancel, so no logarithm ever appears.

Answer−x cot(x/2) + C

The ex(f + f′) standard form

∫ex[f(x) + f′(x)] dx = exf(x) + c. It is derived by parts and is taught inside the by-parts section, but in the exam it is pattern recognition, not working. These four are all short objective questions.

14 ISC Specimen 2022, Semester 2Question 1(iv) 1 mark
∫exx − 1x2 dx = exf(x) + C  — find f(x)
  1. Split the fraction so the pattern shows:
    x − 1x2 = 1x − 1x2
  2. Take f(x) = 1x. Then f′(x) = −1x2 and
    f(x) + f′(x) = 1x − 1x2  ✓
  3. By the identity, the integral is ex f(x) + C.

Answerf(x) = 1x

15 ISC Specimen 2025Question 5(ii) 2 marks
∫ex cosec x (1 − cot x) dx
  1. Expand the bracket:
    ex cosec x (1 − cot x) = ex[cosec x − cosec x cot x]
  2. Recognise f(x) = cosec x, since ddx(cosec x) = −cosec x cot x, so the bracket is exactly f(x) + f′(x).

Answerex cosec x + C

16 CISCE Competency bookletQuestion 10 1 mark
∫2 − x(x − 1)2 ex dx = exf(x) + C  — find f(x)

NoteWatch the sign. f = 1/(x − 1) gives (x − 2)/(x − 1)2, which is the negative of the integrand.

  1. Write 2 − x = 1 − (x − 1) and split:
    2 − x(x − 1)2 = 1(x − 1)2 − 1x − 1
  2. Take f(x) = −1x − 1 = 11 − x. Then f′(x) = 1(x − 1)2 and
    f(x) + f′(x) = 1(x − 1)2 − 1x − 1  ✓

Answerf(x) = 11 − x

17 CISCE Competency bookletQuestion 92 2 marks
∫2x[f′(x) + f(x) log 2] dx

NoteThe same identity with base 2 in place of e. Note that log 2 appears because ddx(2x) = 2x log 2.

  1. Differentiate the product 2x f(x) and compare:
    ddx[2x f(x)] = 2x log 2 · f(x) + 2x f′(x) = 2x[f′(x) + f(x) log 2]
  2. The integrand is that derivative, so integrating undoes it.

Answer2x f(x) + C

Looks like by parts, but is not

These have appeared too, and every one of them punishes a candidate who starts integrating by parts on reflex. Each is worked in full below, so you can see what the right method is.

1 ISC Board 2023, Question 6(i)2 marks
∫cos−1(sin x) dx

Why it is not partsAn inverse function times 1 — the by-parts pattern. But it simplifies away first.

  1. cos−1(sin x) = cos−1[cos(π2 − x)] = π2 − x, valid on the principal branch.
  2. The integrand is now linear:
    I = ∫(π2 − x) dx

Answerπx2 − x22 + C

2 ISC Specimen 2024, Question 1(ii)1 mark
∫sin−1(cos x) dx = g(x) − x22 + C

Why it is not partsThe same trap in objective form. The −x2/2 in the given answer is the giveaway that the integrand became linear.

  1. sin−1(cos x) = π2 − x.
    I = ∫(π2 − x) dx = πx2 − x22
  2. Comparing with g(x) − x2/2 + C.

Answerg(x) = πx2

3 ISC Board 2019 Q13 [6] and ISC Specimen 2021 Q9(b) [4]6 marks
∫π0x tan xsec x + tan x dx

Why it is not partsA definite integral with x multiplying a trigonometric function. The method is the reflection property, not parts.

  1. Apply ∫a0f(x) dx = ∫a0f(a − x) dx with a = π. Since tan(π − x) = −tan x and sec(π − x) = −sec x, the fraction is unchanged:
    I = ∫π0(π − x) tan xsec x + tan x dx
  2. Adding the two expressions for I:
    2I = π ∫π0tan xsec x + tan x dx
  3. Simplify the integrand by multiplying through by cos x:
    tan xsec x + tan x = sin x1 + sin x = 1 − 11 + sin x
  4. and ∫π0dx1 + sin x = 2, so the bracket gives π − 2.

AnswerI = π2(π − 2) ≈ 1·793

4 ISC Specimen 2026, Question 12(ii)6 marks
∫3π4π4x1 + sin x dx

Why it is not partsSame shape, same method — the reflection property in the form f(a + b − x).

  1. Here a + b = π4 + 3π4 = π, and sin(π − x) = sin x, so
    I = ∫3π4π4π − x1 + sin x dx
  2. Adding:
    2I = π ∫3π4π4dx1 + sin x
  3. Rationalise: 11 + sin x = 1 − sin xcos2 x = sec2x − sec x tan x, whose integral is tan x − sec x. Between the limits this gives 2(√2 − 1).

AnswerI = π(√2 − 1) ≈ 1·301

5 ISC Board 2017, Question 1(vi)1 mark
∫π40log(1 + tan θ) dθ

Why it is not partsA logarithm, so parts looks tempting. It is the classic property-based definite integral.

  1. Replace θ by π4 − θ. Then tan(π4 − θ) = 1 − tan θ1 + tan θ, so 1 + tan(π4 − θ) = 21 + tan θ.
    I = ∫π40[log 2 − log(1 + tan θ)] dθ = π4 log 2 − I
  2. So 2I = π4 log 2.

AnswerI = π8 log 2

6 ISC Specimen 2022 Semester 2, Question 1(i)1 mark
∫(log x)2x dx = (log x)kk + C  — find k

Why it is not partsA product of a logarithm and something else — but the “something else” is exactly the derivative of the logarithm, so it is a substitution.

  1. Put t = log x, so dt = dxx.
    I = ∫t2 dt = t33 = (log x)33

Answerk = 3
